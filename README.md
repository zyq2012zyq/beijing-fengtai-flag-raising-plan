# 北京教育学院附属丰台实验学校升旗规划

打开 `index.html` 即可运行。项目为本地静态网页，不需要安装依赖或联网。控制台可切换“国旗 · 国歌”和“校旗 · 校歌”，两段音乐均随项目附带。

## 当前阶段

- 中央五星红旗在国歌前奏结束后升起；国歌环节两面校旗始终保持在旗杆底部。切换到校歌环节时国旗显示在杆顶；校歌播放到 **24.00 秒**后两面校旗同步升起。校旗采用带抽象书本徽记的示意模型，**并非学校正式校旗**。
- 旗面本身不做循环形变动画，位置仅由升旗进度控制。页面底部同时显示国旗与校旗的节拍器目标速度和当前提示读数。
- 三面旗帜的场景示意初始位置均在各自旗杆底部；国旗和两面校旗按各自环节升到杆顶。
- “同步演示”展示目标速度，摇柄自动转动。
- “手摇练习”在未播放时可先预演；正式点击“开始升旗”后，预演圈数清零。前奏期间摇柄待命且不计圈数，到主旋律入点才允许按住圆盘沿圆周拖动。进入升旗段后，暂停时仍可操作。也可用方向键操作（`Shift` + 方向键为整圈）。播放期间国旗高度由手摇进度决定，控制台显示目标圈数与领先或落后的圈数；可听尾音结束时音乐与摇柄动画同时停止，国旗自动到达 60 圈终点，状态栏保留自动补齐前的进度。
- 国歌和校歌各有独立的进度条，可用鼠标、触屏或方向键拖动。定位后，对应旗帜、摇柄、圈数、有效升旗时间和节拍格同步更新；手摇模式可从该位置继续练习。切换环节时播放会暂停。
- 国旗每圈起点提示一次。校旗每圈起点提示主拍、半圈处提示较轻的小拍，合计 104 拍；提示音可关闭。

## 时间与乐拍

项目内音频用 `ffprobe` 测得 **49.52 秒**。检查波形发现末尾为较长的淡出：`ffmpeg silencedetect` 在 −25 dB 门限下从约 **47.765 秒**开始判为静音，在 −35 dB 门限下约 **48.063 秒**开始判为静音。模拟选 **47.80 秒**为可听尾音终点，停止原文件的播放，不改动音频文件本身。此前按 49.52 秒排满 60 圈，最后几圈落在很轻的淡出及静音中，因此听起来音乐在约第 57 圈已结束。

根据[官方管弦乐总谱](https://www.cmab.gov.hk/doc/national_anthem/Orchestra.pdf)，拍号为 **2/4**，速度为 **♩ = 96 BPM**，主旋律的“起”字位于第 6 小节最后一个八分音符，距开头约 **11.5 个四分音符拍**，即 **7.1875 秒**（11.5 × 60 ÷ 96）。页面按两位小数采用 **7.19 秒**作为前奏结束与升旗起点。这是**按官方谱面推算并取整的时间**，不是官方单独公布的录音前奏秒数；录音演奏的实际入点可能有小幅差异。弱起本身不额外增加播放时间；这次结束不同步主要来自录音末尾的淡出。

预定国旗在余下时段升起 **60 圈**：

| 项目 | 计算 | 结果 |
| --- | --- | --- |
| 有效升旗时间 | 47.80 − 7.19 | **40.61 秒** |
| 每圈时间 | 40.61 ÷ 60 | **0.676833 秒** |
| 手摇提示速度 | 60 ÷ 0.676833 | **88.6481 次/分** |
| 原曲四分音符拍长 | 60 ÷ 96 | **0.625 秒/拍** |
| 每圈对应原曲乐拍 | 0.676833 ÷ 0.625 | **1.082933 拍/圈** |

点击“开始升旗”后立即播放国歌。前奏期间两种模式都不升旗、不计圈数，也不播放逐圈提示音；手摇模式的摇柄此时待命。到 **7.19 秒**提示第 1 圈并开始升旗；第 60 圈开始于约 **47.1232 秒**，终点在 **47.80 秒**，音乐和摇柄同时停止。页面分别显示“国歌播放”和“有效升旗”两只计时器。逐圈提示采用平均 **88.65 次/分**，因此不总落在原曲四分音符正拍上；它是手摇操作的独立节拍。若实际手摇速度低于提示速度，仍可能没有亲手转满 60 圈；目标与落后圈数提示用于实时校正速度，结束画面会自动补齐。

## 音频来源

`assets/anthem-orchestra.mp3` 为[香港特别行政区政府政制及内地事务局发布的国歌官方管弦乐版录音](https://www.cmab.gov.hk/sc/issues/national_anthem.htm)；该页面注明资料来源为中华人民共和国中央人民政府网站。录音文件 SHA-256：`c0b338dba010e35cd454c15fe5a7f2ffb3c28cdcfd8502fafbf26ab8d5ee90cd`。[中华人民共和国国防部关于官方录音 96 BPM 的说明](https://www.mod.gov.cn/gfbw/qwfb/yw_214049/16335125.html)。

## 校歌与校旗规划

`assets/school-song.mp3` 来自用户提供的《校歌终极版.mp3》，SHA-256：`aceff408ebe50120a6b8ab832443b60dc8689244e3540f9a7f996e993c3b8218`。用 `ffprobe` 测得原文件约 **91.66 秒**。末尾在约 **86.8 秒**后逐渐低于 −35 dB，模拟以 **86.80 秒**作为可听尾音终点，保留原文件但在此停止播放。

点击“开始升校旗”后立即播放校歌，国旗显示在杆顶。前奏按用户指定的 **24.00 秒**等待；到该时间点开始转圈、发出第 1 圈主拍并同步升起两面校旗。校旗按用户指定的 **52 圈**规划，因此有效升旗时间为 **62.80 秒**，每圈 **1.207692 秒**（62.80 ÷ 52），手摇速度约 **49.68 圈/分**。每圈增加一个半圈小拍，主拍和小拍间隔 **0.603846 秒**，共 **104 拍**，平均约 **99.36 拍/分**。第 52 圈开始于约 **85.5923 秒**，在 **86.80 秒**时校歌和摇柄同步停止，两面校旗到顶。

两面绿色校旗位于 `index.html` 的 `leftSchoolFlag` 与 `rightSchoolFlag` SVG 组中。后续确定校徽、图案、比例、升旗顺序或实际手摇圈数后，可在现有校旗模型与独立控制逻辑上调整。
